One Git Repo to Sync All My Agents

Claude, Codex, and Hermes share one set of skills across three machines — and the only commands I run are git pull and git push.

Gordon Guocheng Qian
July 6, 2026 · 2 min read

The pain

Every AI product now grows its own “skills”: Claude keeps them in ~/.claude/skills, Codex in ~/.codex/skills, Hermes in ~/.hermes/skills. I also work across a Mac mini, a laptop, and a workstation. Teach one agent a trick on one machine, and five other copies of that agent never hear about it. Skills drift, memories fork, and the same rule gets patched in three places, three slightly different ways.

The logic

The whole design fits in one block — and this block is also the part you paste to your agent:

After every git pull, new skills flow in and fan out across agents; before every git push, the state reconciles or the push is refused. Two verbs. Everything else is plumbing that runs itself.

How to get it

Don’t implement this by hand. Hit the copy button on the block above, paste it into any capable agent, and say: “build this for my setup.”

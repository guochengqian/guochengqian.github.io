我用 Claude 20 分钟免费搭了个可评论的博客

一个部署在 GitHub Pages 上的免费简洁博客——点赞、评论、邮件，以及分享到 X、微信、小红书和知乎——全程只靠和 agent 对话搭建。

Gordon Guocheng Qian
2026 年 7 月 5 日 · 阅读约 3 分钟

我把想要的效果告诉 Claude Code，它就在我继续写作的同时，把整个博客悄悄搭了起来。

它能做什么

  • 干净的阅读体验。纯静态页面、衬线字体、跟随系统的深色模式，全站没有任何跟踪器和付费墙。
  • 评论。由 utterances 驱动——每篇文章对应一个 GitHub issue，评论免费、天然防垃圾，而且数据完全归我所有。
  • 点赞。悬浮操作栏里有一个点赞计数器，背后是一个免费的计数 API。不用注册账号，也不用数据库。
  • 分享。一个分享菜单覆盖 X、Facebook、LinkedIn、Substack Notes 和邮件——考虑到我的读者里有很多中文用户，还加上了微信、小红书和知乎；这三家没有分享链接，菜单会直接复制一段即贴即发的文案。
  • 邮件收藏文章。读者输入自己的邮箱地址，文章链接就会在他们自己的邮件客户端里生成一封邮件——完全不经过任何邮件列表服务。

它是怎么搭出来的

上面每一个功能，最初都只是终端里一句随口的话：「给悬浮栏加上上一篇/下一篇箭头」「这个栏在手机上不好用」「再加一个分享到微信」。

Claude 写好代码，用无头浏览器渲染页面来检查自己的成果，按手机宽度截图，然后提交、推送，再盯着 GitHub Pages 的部署，直到线上站点跑起新版本。当部署在 GitHub 那边失败时，它自己发现并重新触发了构建。

有意思的不是 agent 会写博客主题，而是整个闭环——构建、验证、上线、监控——全都装进了一场对话里。

运营这个博客的总成本：零。GitHub Pages 负责托管，GitHub issues 存评论，点赞计数器用的是免费的公共 API。

Title: 「制造和使用工具」是智能体和其他模型的根本区别

会吐 token、能完成任务，不等于智能。

图像、视频、3D 模型也有 token，也能完成任务；但大多数时候，它们仍是在把文本渲染成像素或结构。

我觉得智能体的关键是两件事：

✅ 造工具：会写代码、搭流程，把缺失的能力补出来。

✅ 用工具：会调用 MCP、操作电脑、查资料、跑程序，再根据结果继续行动。

基础大模型只是一个很强的接口。能不断制造和使用工具，才让能力开始外化、积累、递归变强。

也许有一天，机器人控制也只是一句多模态 API 调用。

智能的重点，不是会说话；而是能把世界变成自己的工具箱。

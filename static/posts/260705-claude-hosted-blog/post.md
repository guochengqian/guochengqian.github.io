No Medium. No WordPress. No servers.

I just told Claude Code what I wanted, one sentence at a time:

> "host my blog, keep it clean" → "add comments and likes" → "share to X, WeChat, Rednote" → "make it work on mobile"

It wrote the code, screenshot-tested itself in a headless browser, deployed to GitHub Pages, and watched the deployment until it went green.

- 🧹 Clean serif reading, dark mode
- ❤️ Likes + 💬 comments — backed by GitHub issues, free and spam-proof
- 📤 One-tap share to X / WeChat / Rednote / Zhihu
- ✉️ Email any post to yourself
- 🔁 Every post auto-mirrored to Substack

Blogging in 2026: you edit prose, an agent runs the stack.

模型之后怎么扩

我把这篇 blog 改成一个更短的判断：

模型 scaling 当然还会继续，但对很多日常用户来说，顶级聊天机器人的“知识层”已经够用了。下一步的产品瓶颈，不是“它还知道得不够多”，而是“它还替我做得不够多”。

所以我觉得下一个 scaling 主要是两条：

✅ Context scaling
context 不只是长记忆窗口，它更像推理时的临时学习基质。示例、文档、测试、失败记录、工具输出，都能在不更新权重的情况下改变模型行为。

✅ Agent scaling
从一个聊天机器人，变成几十、几百、甚至上千个 agent 并行工作：读代码、写测试、查文献、跑实验、监控日志、执行任务。

这两条放在一起，真正的瓶颈会从单纯 FLOPS 转向：

✅ HBM 带宽和容量
✅ 推理 ASIC / XPU
✅ AI 网络和光互联
✅ scale-up / scale-out 系统

一句话：上一轮是模型 scaling 拉动 GPU；下一轮可能是 context + agent scaling 拉动 HBM、网络、ASIC 和全栈 AI infra。

所以结论很直白：HBM 短缺还远没结束。不是投资建议，只是我的 AI infra thesis。😂
